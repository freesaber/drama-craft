# 01 产品定位与范围

## 目标用户与成果

为使用 Markdown 和本地素材制作短剧的个人创作者提供 Windows 工作台。作品文件夹是工作目录；离开客户端后，剧本和提示词仍可阅读、编辑和版本管理。

## 当前客户端能力

项目创建与直接打开、最近项目、上级目录候选作品、文档编辑/保存/另存为、默认纵向故事板、手动源码模式、分镜导航、本地媒体预览、外部改动检测与保存冲突保护。现有文档不会因打开或扫描而被改写。

每个 S 编号对应一张视频单元卡片，可包含多个切镜。左侧只展示当前视频，右侧编辑故事走向、视频提示词、时长、分辨率、Seed 和缩略素材。客户端不提供新建文档、剧集结构编辑或分镜新增、删除、移动操作；需要时使用第三方编辑器或 Markdown 源码。无分镜文档显示阅读视图。公共资料与未知内容保留；两种编辑视图共享 Markdown 草稿。

H3 生成链路支持配置服务地址和系统凭据、提交与轮询、结果下载、SQLite 历史和版本切换。客户端实现已由模拟服务测试覆盖；当前没有真实服务上传、计费、结果格式及声音效果的有效账号验收记录。

新项目保留“大纲 → 分集文档 → 分镜”的制作组织方式，素材与视频可与文档同目录保存；子目录和外部素材路径也可引用。现有正文没有固定表单要求。

## 边界

当前版本是 Windows 本地客户端，不自建服务端或 OSS。视频请求只发往用户配置的服务地址。客户端没有文本模型生成、全局素材库、分镜合并、多轨时间线、转场、字幕编辑、自动备份或项目打包功能；首帧图片由外部工具制作后导入或通过路径引用。历史生成版本可用打包的 FFmpeg 裁切片头片尾，并覆盖原视频文件。

一个项目可以包含多集。每个 S 编号对应一张故事板卡片和一次视频请求，可在提示词中描述多个切镜，但客户端不把段内切镜拆成独立结构。

## 成功标准

新项目可在自选位置建立；旧项目保持原样接入；中文路径可用；外部编辑与客户端保存发生竞争时不静默覆盖；未知 Markdown 内容可往返保存。具体测试与当前验证记录见 [07](07-开发指南与验收.md)。
