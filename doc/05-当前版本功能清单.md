# 05 当前版本功能清单

本文只记录当前客户端已经存在的功能。未进入客户端的设想不写入本清单。

## 项目与文档

- 在自选父目录下创建新项目，生成项目文件夹、项目元数据、故事大纲和分镜总表。
- 直接打开已有作品目录；当选择的目录包含多个候选作品时，可以继续选择子项目或将当前目录作为项目打开。
- 记录最近打开的项目；项目移动后可重新选择目录打开。
- 扫描项目内 Markdown 文档，新建分集剧本、故事大纲、分镜总表或空白文档。
- 提供显式保存、`Ctrl+S`、刷新、重新读取磁盘版本和另存为。
- 关闭、返回首页、切换文档或覆盖草稿前提示未保存修改。

## 故事板与源码

- 有分镜的文档默认显示纵向故事板；普通文档显示阅读视图；顶部可以切换到 Markdown 源码。
- 左侧文档列表展示分镜导航，可跳转到对应 S 编号卡片。
- 卡片可编辑镜头标题、故事走向、首帧提示词、视频提示词、时长、分辨率、首帧文件名和视频文件名。
- 支持新增、删除及相邻移动分镜。新增编号取现有最大编号加一，不自动重排已有镜号；独立资料隔开的分镜不能跨区移动。
- 卡片与源码共用同一份草稿。局部修改使用源范围补丁；重复或歧义字段转交源码模式，不丢弃未知内容。

## 剧集资料与素材

- v1 分集解析本集梗概、角色与声音绑定、场景与道具、台词及分镜角色关系；旧格式文档通过兼容适配器读取。
- 故事板展示角色图、音色绑定、素材和本镜台词，但这些复杂表格当前通过源码模式编辑。
- 识别 Markdown 链接、图片、引用式链接和行内代码中的本地素材路径，检查文件是否存在。
- 在接近可视区域时加载图片、音频和视频；解码失败的文件可使用系统应用打开。
- 视频生成面板允许导入本地参考图片或音频副本，替换本次请求的对应输入。

## 视频生成与版本

- “视频 API”可以保存多组命名配置，每组包含 Base URL 和完整 `Authorization` 请求头，并选择当前配置。
- Authorization 保存在 Windows 凭据管理器；项目 JSON、Markdown 和 SQLite 不保存密钥。
- 按 H3 协议提交视频提示词、时长、分辨率、Seed、最多 9 张参考图片和最多 3 段参考音频。本地素材编码为 data URL，HTTP(S) 引用保持 URL。
- 收到远端 `task_id` 后写入项目内 SQLite，每 3 秒查询任务；重新打开对应分镜时继续查询已知任务。
- 完成结果流式下载到分集文档旁，经临时文件原子落盘，然后在无保存冲突时更新 Markdown 的当前视频文件名。
- 每个分镜显示最近 50 条生成记录；有本地文件的历史记录可以重新设为当前视频。
- 查询网络错误会继续轮询；下载失败不会重新提交生成。提交超时不会自动重发计费请求。

## 数据保护与安全边界

- Markdown 是正文唯一可编辑原件；`.drama-craft/project.json` 保存便携项目身份；`.drama-craft/generations.sqlite3` 保存生成任务和版本索引。
- 保存使用内容哈希前置条件和同目录原子替换，外部改动或文件删除不会被静默覆盖。
- 文档写入限制在已打开项目内，拒绝父级跳转、绝对文档路径、隐藏目录、Windows 保留名称和符号链接逃逸。
- Markdown 不执行原始 HTML，正文链接不直接导航，远程图片不自动请求；项目内的 `AGENTS.md` 只作为内容读取。

## 当前限制与验证状态

客户端没有文本模型生成、全局素材库、视频拼接、时间线、字幕编辑、后台常驻轮询、任务取消、自动备份或项目打包功能。外部绝对路径素材不会随项目复制。媒体预览取决于系统 WebView2 编解码能力。

H3 提交、查询、Base64 编码、下载和历史记录已经通过本地模拟服务测试；当前没有真实账号上传、计费生成、结果下载或音色效果的验收记录，因此文档不宣称真实服务行为已验证。
