# 05 当前版本功能清单

本文只记录当前客户端已经存在的功能。未进入客户端的设想不写入本清单。

## 项目与文档

- 在自选父目录下创建新项目；成功创建后在本机记住父目录、角色目录和声音目录，下次创建自动填入；首次使用时声音目录默认使用客户端内置的 25 个 TTS 样本并允许改选、可从资源管理器打开，角色目录可选；只保存目录配置，不复制素材，再生成项目元数据、根目录 `assets.json` 空索引、故事大纲和全剧人物与对白模板。
- 直接打开已有作品目录；当选择的目录包含多个候选作品时，可以继续选择子项目或将当前目录作为项目打开。
- 旧项目缺少素材库配置时必须先补充声音目录；角色目录可留空。保存配置不修改原有 Markdown 和提示词。
- 记录最近打开的项目；项目移动后可重新选择目录打开。
- 扫描并打开项目内 Markdown 文档；新建文档使用第三方编辑器完成，再通过刷新载入客户端。
- 提供显式保存、`Ctrl+S`、刷新、重新读取磁盘版本和另存为。
- 关闭、返回首页、切换文档或覆盖草稿前提示未保存修改。

## 故事板与源码

- 有分镜的文档默认显示纵向故事板；普通文档显示阅读视图；顶部可以切换到 Markdown 源码。
- `AGENTS.md` 阅读视图不显示额外的「素材引用」区域，避免将创作规则中的示例文件作为项目素材展示。
- 新项目 `AGENTS.md` 的自检与验收条目使用普通圆点列表。
- Markdown 任务清单的只读复选框与文字同行显示，长文本换行沿用文字缩进，不附加普通列表圆点。
- 左侧文档列表展示分镜导航，可跳转到对应 S 编号卡片。
- 卡片可编辑镜头标题、故事走向、首帧提示词、视频提示词、时长、分辨率、首帧文件名和视频文件名。分辨率下拉按当前 API 列表对齐同标签项（如 `480p横` 显示为 `480p横(864*480)`），切换配置不改写 Markdown。
- 客户端不提供剧集结构编辑或分镜新增、删除、移动操作；需要时使用第三方编辑器或 Markdown 源码。
- 卡片与源码共用同一份草稿。局部修改使用源范围补丁；重复或歧义字段转交源码模式，不丢弃未知内容。
- 分镜卡片可「丢弃 / 取消丢弃」。该标签写入 `.drama-craft/shot-flags.json`，不改 Markdown；合并弹窗中已丢弃行标红且默认不勾选。

## 剧集资料与素材

- v1 分集解析本集梗概、角色与声音绑定、场景与道具、台词及分镜角色关系；旧格式文档通过兼容适配器读取。
- 故事板展示角色图、音色绑定、素材，以及由声音安排表汇总的本集台词表格（镜号、角色名称、台词）；台词列可按表格行序一键复制；复杂表格仍通过源码模式编辑。
- 识别 Markdown 链接、图片、引用式链接和行内代码中的本地素材路径，检查文件是否存在。
- 在接近可视区域时加载图片、音频和视频；解码失败的文件可使用系统应用打开。
- 首帧、角色图和本集素材的「上传／替换」把所选图片保存为 Markdown 中的既有文件名；替换时覆盖原文件并删除旧内容，不改名、不另存副本。
- 视频生成面板允许导入本地参考图片或音频副本，替换本次请求的对应输入。

## 视频生成与版本

- 历史生成版本提供「删除」与二次确认，同时删除记录和对应的项目内本地视频；当前版本需先切换，Markdown 仍引用的视频、生成中或批量任务待处理的版本不可删除。视频文件已缺失时可清理历史记录；已完成批量明细中的对应本地视频引用同步清空。
- “视频 API”可以保存多组命名配置：类型（默认 AutoDL）、提交/查询接口、resolution JSON 列表、默认 seed、完整 `Authorization` 请求头，并选择当前配置。
- “音频 API”独立保存多组命名配置：类型（当前 AutoDL）、IndexTTS2 提交/查询接口和完整 `Authorization` 请求头。凭据仍只在机器本地保存，不进入项目或 SQLite。
- Authorization 保存在本机应用数据目录的配置文件；项目 JSON、Markdown 和 SQLite 不保存密钥。设置界面支持显示、隐藏 Token 和删除 API 配置。
- 故事板分镜只读展示视频提示词，不在卡片中提供编辑；单镜点击生成后打开左右分栏确认弹框，弹框内可调整时长、分辨率、Seed 和本次提示词，左侧勾选本次提交的图片与音频，第一张首帧固定勾选。取消中间素材时，后续 Picture / Audio 标签与请求参数连续重排；正文仍引用已取消标签时显示警告并阻止提交。弹框编辑不改写 Markdown。
- 按 H3 协议提交视频提示词、时长、分辨率、Seed、最多 9 张参考图片和最多 3 段参考音频。本地素材编码为 data URL，HTTP(S) 引用保持 URL。
- 收到远端 `task_id` 后，将本次实际提交的提示词、图片引用和音频引用一并写入项目内 SQLite，每 3 秒查询任务；历史重新生成优先复用当时的素材参数，旧记录未保存素材参数时回退到当前分镜的默认素材。
- 完成结果流式下载到分集文档旁，经临时文件原子落盘，然后在无保存冲突时更新 Markdown 的当前视频文件名。
- 每个分镜显示最近 50 条生成记录；每条记录可从列表打开生成确认弹框，按当前分镜初始化完整提示词与素材清单，再根据当次提交的文件引用恢复素材勾选，并带入原时长、分辨率和 Seed。之前取消的素材仍会显示为未勾选，可重新选择。有本地文件的历史记录还可以播放、打开裁切弹窗或重新设为当前视频；播放弹框不提供重新生成操作，提交提示词仅只读展示。
- 裁切弹窗上方预览画面，下方拖动时间轴入点/出点；保存后用打包的 FFmpeg 覆盖原 MP4，不保留裁切前文件，也不更新 Markdown。
- 提供本集「合并」：较大弹窗左侧列出各分镜当前视频，默认勾选未丢弃且已落盘的视频；已丢弃分镜标红且默认不勾选，仍可手动勾选。点击行只切换右侧预览，只有复选框会改勾选。提交后在后台重编码拼接为 `0001 merge_时间戳.mp4`，不改 Markdown，并写入任务列表；同一集已有进行中的合并任务时不能再提交。
- 查询网络错误会继续轮询；下载失败不会重新提交生成。单镜历史与批量任务详情提供“重试下载”，复用原 API 任务重新取得结果，成功后下载并写回当前视频。提交超时不会自动重发计费请求。
- 提供本集「批量生成」：筛选视频文件尚未落盘、提示词与参考素材齐全的分镜（v1 占位文件名不算已生成），分辨率按当前 API 配置列表匹配完整项后快照；可立刻或延时 1—12 小时提交；创建生成类主子任务。
- 提供本集「批量音频」：读取声音安排表，按角色聚合台词，使用角色表绑定的音色参考提交 IndexTTS2；弹框可为整批任务设置情绪控制方式、随机情绪和七项 `0—1.4` 情绪向量；每个角色下载一个 `四位集号_角色名_时间戳.扩展名` 文件，不修改 Markdown。未绑定音色的角色不可勾选。
- 提供项目级「任务列表」页：按类型查看视频生成、音频生成和合并任务、取消整任务或未提交明细，并查看明细弹窗；已完成明细可按任务类型使用视频或音频播放器播放本地结果，合并任务详情可播放本次成片。
- 客户端在项目打开期间轮询到期批量任务；生成任务按分镜串行提交，上一镜有查询结果并写回视频文件名后才处理下一镜。取消的明细不会再提交。已提交到远端的单项无法由客户端强制中止远端执行。

## 数据保护与安全边界

- Markdown 是正文唯一可编辑原件；`.drama-craft/project.json` 保存项目身份和用户选择的角色、声音目录；`.drama-craft/shot-flags.json` 保存分镜丢弃标签；`.drama-craft/generations.sqlite3` 保存生成任务和版本索引。
- 根目录 `assets.json` 供外部创作 agent 维护作品级角色与可复用素材索引；界面不提供“作品资产”入口或独立索引展示，分集角色与素材仍可通过索引读取首现集提示词并校验，旧项目缺少索引时正常打开。新项目的 C/A/N/S 编号示例采用四位，旧三位编号保持兼容。
- 保存使用内容哈希前置条件和同目录原子替换，外部改动或文件删除不会被静默覆盖。
- 文档写入限制在已打开项目内，拒绝父级跳转、绝对文档路径、隐藏目录、Windows 保留名称和符号链接逃逸。
- Markdown 不执行原始 HTML，正文链接不直接导航，远程图片不自动请求；项目内的 `AGENTS.md` 只作为内容读取。

## 当前限制与验证状态

客户端没有文本模型生成、全局素材库、多轨时间线、字幕编辑、关闭后常驻后台轮询、自动备份、素材归集或项目打包功能。生成的角色音频只供外部剪辑软件手工使用，不自动回写声音安排或视频轨。历史生成视频可裁切片头片尾；本集当前视频可按勾选顺序合并。媒体预览取决于系统 WebView2 编解码能力。批量任务仅在项目保持打开时推进排程与轮询。

H3 提交、查询、Base64 编码、下载和历史记录已经通过本地模拟服务测试；当前没有真实账号上传、计费生成、结果下载或音色效果的验收记录，因此文档不宣称真实服务行为已验证。
