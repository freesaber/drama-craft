# 06 模型接入与生成任务设计

本文描述当前 H3 客户端链路、任务处理方式和验证状态。

## H3 服务商边界

“视频 API”设置支持添加多组命名配置（Base URL 和完整 Authorization 请求头），通过下拉选择当前配置，保存后统一用于新提交；令牌进入 Windows 凭据管理器，项目和 SQLite 均不保存。Rust 随客户端执行网络请求，无须独立部署后端。当前客户端只实现下表所列的 H3 协议，不包含文本模型或其他视频协议适配器。

接口实现采用以下请求格式。表格描述客户端实际发送的内容，不代表服务商已用有效账号验收。

| 项目 | 当前实现 |
|---|---|
| 提交 | `/api/v1/comfyui/comfyui_workflow/minimax_h3_zm_u24` |
| 查询 | `/api/v1/comfyui/comfyui_workflow/result/{task_id}` |
| 鉴权 | 用户填写完整 `Authorization` 值，不默认添加 Bearer 或 Token |
| 提示词 | prompt，1—10000 字符 |
| 时长 | duration，整数 1—15 秒 |
| 分辨率 | 480p/768p 横、竖、1:1，按接口实际枚举 |
| 图片 | ref_image_0 至 ref_image_8；至少一张，最多九张 |
| 音频 | ref_audio_0 至 ref_audio_2；最多三段 |
| 随机种子 | seed，默认 683072603085674，可修改或清空以省略 |

`ref_image_0` 对应 `<Picture 1>`，`ref_audio_0` 对应 `<Audio 1>`；映射在每次请求重新建立，图片与音频独立编号。首帧 GPT 附件编号不直接继承为 H3 参数。实际模型是否遵从标签与说话人安排需要样片验证。

## 本地素材、任务和版本

本地 JPG/PNG/WebP 图片及 MP3/WAV/FLAC/MP4 音频按 data URL Base64 放入 JSON；HTTP(S) 引用保持 URL。界面从首帧、出场角色和本镜素材建立图片序列，从角色音色建立音频序列，分别限制为 9 张和 3 段。缩略图可放大查看，也可导入本地文件覆盖本次输入；导入副本保存在分集文档旁。

时长 1—15 秒和六种分辨率均可下拉选择；旧文档中的非标准值保留显示，不自动改写。卡片隐藏故事走向、出场/发声角色与本镜台词区，原 Markdown 内容保留；参考图片和音频排列在视频下方。

提交返回 `task_id` 后立即写入 `.drama-craft/generations.sqlite3`。新任务同时记录配置 ID 与服务地址，不保存密钥。切换默认配置不影响新记录任务的查询；若其配置的服务地址被修改，查询会要求恢复原地址。升级前的记录缺少绑定，仍使用当前配置。旧版单配置会在设置中显示为默认 API，沿用原凭据。客户端每 3 秒查询已知任务；重开对应分镜时恢复查询。成功结果流式下载到同目录临时文件，再原子落为 `01 S001_年月日-时分秒.mp4`。随后使用当前 Markdown 草稿及原始内容哈希修改“视频文件名”；发生外部冲突时保留草稿和下载结果，不静默覆盖。SQLite 保存任务参数、状态、远端地址和本地文件索引，Markdown 只保存当前选中的视频。历史版本可重新设为当前。

## 当前验证状态

本地模拟服务已验证客户端图片、音频 data URL 编码、请求头、提交与查询路径、结果下载和 SQLite 记录。当前没有有效账号完成的真实上传或计费请求记录，因此服务端是否接受这些请求、实际状态枚举、结果 URL 鉴权、过期时间及分辨率枚举均未验证。客户端不提供 OSS 上传中转。

客户端把参考音频作为音色样本提交，但没有真实样片证明服务端会用该声音生成新台词，也没有验证多角色音频对应关系或画内外音效果。界面中的音色绑定状态只表示文件引用存在，不表示声音效果通过试听。

## 当前失败与恢复行为

客户端只在收到远端 `task_id` 后记录任务。若请求已经到达服务端但客户端没有收到响应，本地没有可续查的 task ID；客户端不会自动重发计费请求，也不能自动核对该次提交。

已知任务按固定 3 秒间隔查询。查询网络错误会继续轮询；生成失败记录远端状态与错误；下载失败标记为 `download_failed`，不会重新生成，也没有单独的下载重试按钮。客户端没有任务取消、托盘后台运行或关闭后常驻轮询。

Authorization 存于 Windows 凭据管理器；日志和项目文件不带密钥。真实 H3 上传、计费生成与音色行为没有验收记录，编译和模拟服务测试不等同于真实服务验证。
