# 06 模型接入与生成任务设计

本文描述当前 H3 客户端链路、任务处理方式和验证状态。

## H3 服务商边界

“视频 API”设置支持添加、删除多组命名配置。每组包含：**类型**（当前默认/仅实现 `AutoDL`，预留即梦等）、**提交任务接口**、**查询任务接口**（`{task_id}` 占位）、**resolution JSON 列表**、**默认 seed**、以及完整 Authorization 请求头。通过下拉选择当前配置，保存后统一用于新提交；令牌进入本机应用数据目录的偏好配置，项目和 SQLite 均不保存。“从 AutoDL 模型添加”提供 `minimax_h3_zm_u30`、`minimax_h3_803` 两套预设，自动填入官方提交/查询地址、resolution 列表和 seed；也可添加空白配置手填，或自行编辑预设字段。添加预设不会复制其他配置的令牌。分镜分辨率下拉与 seed 预填均解析当前配置；批量生成同样快照当前默认 seed，留空则省略。Rust 随客户端执行网络请求，无须独立部署后端。当前客户端只实现 AutoDL H3 协议体，不包含文本模型或其他视频协议适配器。

U30 根据接口截图预填分辨率 `480p横`、`480p竖`、`768p横`、`768p竖`、`960p横`、`960p竖` 和 seed `548628410878779`。U30 真实服务生成尚未验证。

`minimax_h3_803` 根据服务商接口截图新增：默认 seed 为整数 `803`；分辨率按顺序为 `480p竖(480*864)`、`768p竖(768*1376)`、`1088p竖(1088*1920)`、`1440p竖(1440*2560)`、`480p横(864*480)`、`768p横(1376*768)`、`1088p横(1920*1088)`、`1440p横(2560*1440)`。使用半角括号和 `*`，其中 `1088p` 不替换为旧模型的 `1080p`。支持既有 1—9 图、0—3 音频及 1—15 秒请求结构；无音频仍提交到 803。可选 `mode` 暂不发送，沿用服务端默认。已通过本地模拟请求回归，真实服务生成和音色效果尚未验证。

接口实现采用以下请求格式。表格描述客户端实际发送的内容，不代表服务商已用有效账号验收。

| 项目 | 当前实现 |
|---|---|
| 类型 | 配置项 `type`，默认 `autodl` |
| 提交 | 当前配置的完整提交 URL（模型预设可自动填入） |
| 查询 | 当前配置的查询 URL；推荐含 `{task_id}`，模型预设可自动填入 |
| 鉴权 | 用户填写完整 `Authorization` 值，不默认添加 Bearer 或 Token |
| 提示词 | prompt，1—20000 字符 |
| 时长 | duration，整数 1—15 秒 |
| 分辨率 | 来自配置中的 JSON 字符串数组（须带像素后缀，如 `768p横(1376*768)`）；旧 Markdown 短名提交时自动补全 |
| 默认 seed | 配置项；生成面板预填，可改或清空后省略 |
| 图片 | ref_image_0 至 ref_image_8；至少一张，最多九张 |
| 音频 | ref_audio_0 至 ref_audio_2；最多三段 |

`ref_image_0` 对应 `<Picture 1>`，`ref_audio_0` 对应 `<Audio 1>`；映射在每次请求重新建立，图片与音频独立编号。单镜提交前允许取消除第一张首帧外的素材；客户端按保留顺序连续重排请求参数和提示词标签，不发送中间空槽。若取消素材的标签仍用于提示词正文，确认弹框会标记残留并阻止提交。弹框中的提示词仅用于本次请求，不改写 Markdown。首帧 GPT 附件编号不直接继承为 H3 参数。实际模型是否遵从标签与说话人安排需要样片验证。

每条生成历史同时保存当次实际提交的提示词、时长、分辨率、Seed、`image_refs` 与 `audio_refs`。历史列表的“重新生成”使用与首次生成相同的确认弹框：提示词和素材列表从当前分镜完整初始化，再按历史中的文件引用恢复勾选状态，因此上次取消的素材仍可见但默认不勾选；时长、分辨率和 Seed 先使用历史值，并允许在确认弹框内重新编辑。素材按文件引用而不是已压缩的 Picture / Audio 编号匹配。兼容读取没有素材字段的旧 SQLite 记录，此类记录默认勾选当前分镜推导出的全部图片与音频。播放弹框只展示视频和只读提交信息，不承担重新提交。

## 本地素材、任务和版本

本地 JPG/PNG/WebP 图片及 MP3/WAV/FLAC/MP4 音频按 data URL Base64 放入 JSON；HTTP(S) 引用保持 URL。界面优先读取本镜「视频生成」区的 `API参数 | 提示词标签 | 上传素材` 映射表，按 `ref_image_*` / `ref_audio_*` 顺序组装请求；**只要该表存在，就以表为准**（表中没有 `ref_audio_*` 时不上传音频，也不会用角色音色回填）。仅当整张映射表缺失时，才回退到首帧、出场角色与本镜素材引用。分别限制为 9 张和 3 段。缩略图可放大查看。首帧文件在下方首帧区按 Markdown 固定文件名上传或替换：所选图片覆盖同名原文件，不改 Markdown 中的出图文件名，也不另存带新名字的副本；视频区参考素材只读展示，不再支持临时替换或追加。

时长 1—15 秒；分辨率下拉选项来自当前 API 配置的 JSON 列表。切换 API 不会改写本集 Markdown：短标签与带像素后缀的完整项只要标签相同（如 `480p横` 与 `480p横(864*480)`），下拉只显示当前配置中的对应项；单镜提交和批量快照同样匹配后发送，用户未改该分镜时不写回源文。对不上的值仍单独显示。卡片隐藏故事走向、出场/发声角色与本镜台词区，原 Markdown 内容保留；参考图片和音频排列在视频下方。

提交返回 `task_id` 后立即写入 `.drama-craft/generations.sqlite3`。新任务同时记录配置 ID 与提交地址，不保存密钥。切换默认配置不影响已记录任务的查询；若其配置的提交地址被修改，查询会要求恢复原地址。升级前的记录缺少绑定，仍使用当前配置。旧版仅含 `baseUrl` 的配置会迁移为 submit/query，并按 URL 补全 AutoDL resolution/seed 预设。客户端每 3 秒查询已知任务；重开对应分镜时恢复查询。成功结果流式下载到同目录临时文件，再原子落为 `0001 S0001_年月日-时分秒.mp4`。随后使用当前 Markdown 草稿及原始内容哈希修改“视频文件名”；发生外部冲突时保留草稿和下载结果，不静默覆盖。SQLite 保存任务参数、状态、远端地址和本地文件索引，Markdown 只保存当前选中的视频。历史版本可播放、裁切片头片尾（覆盖原 MP4，不改 Markdown）或重新设为当前。

同一数据库另存批量任务主表 `batch_jobs` 与明细表 `batch_job_items`。批量生成在创建时快照各分镜提示词与素材引用，支持立刻或最多延时 12 小时提交；项目打开期间客户端推进到期明细并复用单镜 H3 提交。同一项目同一时刻只向服务商提交一个进行中的分镜：上一镜查询到完成、失败或下载失败等结果，并写回当前文档的视频文件名后，才提交下一镜，避免并发占满算力或同时改写 Markdown。可取消整任务（未提交明细一并取消）或取消单条未提交明细；已提交远端的明细不能由客户端撤回。任务列表按类型展示视频生成、音频生成与合并任务。合并按勾选分镜的当前视频顺序在后台解码后统一重编码，拼接为文档旁的 `0001 merge_时间戳.mp4`，不改 Markdown；同一集同时只允许一个进行中的合并任务。任务记录保存成片文件名，详情中可播放。

## IndexTTS2 角色音频

“音频 API”与视频配置分离，支持多组命名配置并选择当前配置；当前只实现 AutoDL `indextts2-v1` 协议，提交与查询 URL 均可编辑，查询 URL 使用 `{task_id}`。Authorization 仍只保存在机器本地偏好中。批量音频读取 v1 声音安排表，将同一角色的台词按表格顺序以换行聚合，并使用角色绑定的音色文件同时填入 `prompt_simple` 与 `emo_ref_audio`。弹框允许为整批角色选择三种情绪控制方式、随机情绪及开心、平静、悲伤、愤怒、恐惧、厌恶、忧郁七项 `0—1.4` 情绪向量；参数随任务快照保存。选择“使用情感参考音频”时，当前仍以该角色绑定的音色文件作为情感参考。服务端将 `emo_surprised` 定义为字符串枚举，但未展示除 `"0"` 外的有效选项，客户端固定发送 `"0"`。单角色文本遵守接口 2048 字符限制。

音频任务复用项目 SQLite 批量队列，每次只推进一个角色。成功结果下载到分集文档旁，文件名为 `四位集号_角色名_年月日-时分秒.服务端扩展名`；非法文件名字符会替换为下划线，冲突时追加任务 ID。音频结果不写回 Markdown，也不自动导入剪辑轨。

## 当前验证状态

本地模拟服务已验证 H3 客户端图片、音频 data URL 编码、请求头、提交与查询路径、结果下载和 SQLite 记录。IndexTTS2 新链路已有请求体、配置安全、任务建档与文件命名单元测试，但尚未用真实 AutoDL 账号验证提交、计费、状态枚举、结果下载或音色效果。客户端不提供 OSS 上传中转。

客户端把参考音频作为音色样本提交，但没有真实样片证明服务端会用该声音生成新台词，也没有验证多角色音频对应关系或画内外音效果。界面中的音色绑定状态只表示文件引用存在，不表示声音效果通过试听。

## 当前失败与恢复行为

客户端只在收到远端 `task_id` 后记录任务。若请求已经到达服务端但客户端没有收到响应，本地没有可续查的 task ID；客户端不会自动重发计费请求，也不能自动核对该次提交。

已知任务按固定 3 秒间隔查询。查询网络错误会继续轮询；生成失败记录远端状态与错误；下载失败标记为 `download_failed`，不会重新生成。单镜历史与批量任务详情可对原 API 任务执行“重试下载”；成功后复用正常的版本选择流程写回 Markdown，不发起新的计费生成请求。客户端没有关闭后常驻轮询或系统托盘后台运行；批量排程仅在项目打开时推进。未提交的批量明细可以取消；已提交到服务商的单项无法由客户端强制中止。

Authorization 存于本机应用数据目录的偏好配置；日志和项目文件不带密钥。真实 H3 上传、计费生成与音色行为没有验收记录，编译和模拟服务测试不等同于真实服务验证。
