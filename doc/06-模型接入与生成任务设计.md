# 06 模型接入与生成任务设计

本文描述当前 H3 客户端链路、任务处理方式和验证状态。

## H3 服务商边界

“视频 API”设置支持添加、删除多组命名配置。每组包含：**类型**（当前默认/仅实现 `AutoDL`，预留即梦等）、**提交任务接口**、**查询任务接口**（`{task_id}` 占位）、**resolution JSON 列表**、**默认 seed**、以及完整 Authorization 请求头。通过下拉选择当前配置，保存后统一用于新提交；令牌进入本机应用数据目录的偏好配置，项目和 SQLite 均不保存。提交/查询地址不提供默认值，须手填。AutoDL 可一键填入两套 resolution/seed 预设（`minimax_h3_zm_u24`、`minimax_h3_z0903`），也可自行编辑 JSON。分镜分辨率下拉与 seed 预填均解析当前配置，不再按 URL 硬编码。Rust 随客户端执行网络请求，无须独立部署后端。当前客户端只实现 AutoDL H3 协议体，不包含文本模型或其他视频协议适配器。

接口实现采用以下请求格式。表格描述客户端实际发送的内容，不代表服务商已用有效账号验收。

| 项目 | 当前实现 |
|---|---|
| 类型 | 配置项 `type`，默认 `autodl` |
| 提交 | 用户填写的完整提交 URL（无默认） |
| 查询 | 用户填写的查询 URL；推荐含 `{task_id}`（无默认） |
| 鉴权 | 用户填写完整 `Authorization` 值，不默认添加 Bearer 或 Token |
| 提示词 | prompt，1—10000 字符 |
| 时长 | duration，整数 1—15 秒 |
| 分辨率 | 来自配置中的 JSON 字符串数组（须带像素后缀，如 `768p横(1376*768)`）；旧 Markdown 短名提交时自动补全 |
| 默认 seed | 配置项；生成面板预填，可改或清空后省略 |
| 图片 | ref_image_0 至 ref_image_8；至少一张，最多九张 |
| 音频 | ref_audio_0 至 ref_audio_2；最多三段 |

`ref_image_0` 对应 `<Picture 1>`，`ref_audio_0` 对应 `<Audio 1>`；映射在每次请求重新建立，图片与音频独立编号。首帧 GPT 附件编号不直接继承为 H3 参数。实际模型是否遵从标签与说话人安排需要样片验证。

## 本地素材、任务和版本

本地 JPG/PNG/WebP 图片及 MP3/WAV/FLAC/MP4 音频按 data URL Base64 放入 JSON；HTTP(S) 引用保持 URL。界面优先读取本镜「视频生成」区的 `API参数 | 提示词标签 | 上传素材` 映射表，按 `ref_image_*` / `ref_audio_*` 顺序组装请求；**只要该表存在，就以表为准**（表中没有 `ref_audio_*` 时不上传音频，也不会用角色音色回填）。仅当整张映射表缺失时，才回退到首帧、出场角色与本镜素材引用。分别限制为 9 张和 3 段。缩略图可放大查看。首帧文件在下方首帧区按 Markdown 固定文件名上传或替换；视频区参考素材只读展示，不再支持临时替换或追加。

时长 1—15 秒；分辨率下拉选项来自当前 API 配置的 JSON 列表。旧文档中的非标准值保留显示，不自动改写。卡片隐藏故事走向、出场/发声角色与本镜台词区，原 Markdown 内容保留；参考图片和音频排列在视频下方。

提交返回 `task_id` 后立即写入 `.drama-craft/generations.sqlite3`。新任务同时记录配置 ID 与提交地址，不保存密钥。切换默认配置不影响已记录任务的查询；若其配置的提交地址被修改，查询会要求恢复原地址。升级前的记录缺少绑定，仍使用当前配置。旧版仅含 `baseUrl` 的配置会迁移为 submit/query，并按 URL 补全 AutoDL resolution/seed 预设。客户端每 3 秒查询已知任务；重开对应分镜时恢复查询。成功结果流式下载到同目录临时文件，再原子落为 `01 S001_年月日-时分秒.mp4`。随后使用当前 Markdown 草稿及原始内容哈希修改“视频文件名”；发生外部冲突时保留草稿和下载结果，不静默覆盖。SQLite 保存任务参数、状态、远端地址和本地文件索引，Markdown 只保存当前选中的视频。历史版本可重新设为当前。

同一数据库另存批量任务主表 `batch_jobs` 与明细表 `batch_job_items`。批量生成在创建时快照各分镜提示词与素材引用，支持立刻或最多延时 12 小时提交；项目打开期间客户端推进到期明细并复用单镜 H3 提交。可取消整任务（未提交明细一并取消）或取消单条未提交明细；已提交远端的明细不能由客户端撤回。任务列表按类型展示，当前实现生成任务，合并任务类型已预留。

## 当前验证状态

本地模拟服务已验证客户端图片、音频 data URL 编码、请求头、提交与查询路径、结果下载和 SQLite 记录。当前没有有效账号完成的真实上传或计费请求记录，因此服务端是否接受这些请求、实际状态枚举、结果 URL 鉴权、过期时间及分辨率枚举均未验证。客户端不提供 OSS 上传中转。

客户端把参考音频作为音色样本提交，但没有真实样片证明服务端会用该声音生成新台词，也没有验证多角色音频对应关系或画内外音效果。界面中的音色绑定状态只表示文件引用存在，不表示声音效果通过试听。

## 当前失败与恢复行为

客户端只在收到远端 `task_id` 后记录任务。若请求已经到达服务端但客户端没有收到响应，本地没有可续查的 task ID；客户端不会自动重发计费请求，也不能自动核对该次提交。

已知任务按固定 3 秒间隔查询。查询网络错误会继续轮询；生成失败记录远端状态与错误；下载失败标记为 `download_failed`，不会重新生成，也没有单独的下载重试按钮。客户端没有关闭后常驻轮询或系统托盘后台运行；批量排程仅在项目打开时推进。未提交的批量明细可以取消；已提交到服务商的单项无法由客户端强制中止。

Authorization 存于本机应用数据目录的偏好配置；日志和项目文件不带密钥。真实 H3 上传、计费生成与音色行为没有验收记录，编译和模拟服务测试不等同于真实服务验证。
