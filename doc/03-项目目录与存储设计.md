# 03 项目目录与存储设计

[English](../en/03-workspace-storage.md) · [目录](../README.md)

## 已实现：文件为主

```text
原创作品/
  .drama-craft/project.json
  .drama-craft/generations.sqlite3  # 首次提交生成任务时建立
  剧本大纲.md
  分镜总表.md
  01 第一集.md
  01 首帧_S001.png
  01 S001.mp4
  assets/                 # 可选，支持子目录引用
```

创建项目在选定父目录下创建同名文件夹，已有同名目录时报错；不会自动清理创建失败后留下的文件。打开旧项目仅尝试增加项目元数据，不移动、重命名或改写原文档。扫描排除隐藏目录、node_modules、target、dist 和符号链接。

元数据 `project.json` 保存 `id`、`name`、`formatVersion: 1`、`layout: "preserve"`。根目录不写入其中，移动目录后重新打开仍保留项目 ID。格式版本不支持或 JSON 损坏时明确报错，不覆盖。只读目录无法建立元数据时使用临时身份并提示，仍可浏览可读文档。

最近项目及预览偏好保存在 Tauri 应用数据目录的 `preferences.json` 中；该文件可以包含当前电脑的绝对路径，不随项目分发。复制带元数据的目录是同一项目的副本，P0 不提供“克隆为新身份”功能。

## 保存语义

读取以原始字节计算 SHA-256，向编辑器提供规范化 LF 文本。保存必须提交原哈希；磁盘内容改变或文件被删除时拒绝覆盖。原 UTF-8 BOM 和 CRLF 风格保留，新文件使用无 BOM 的 UTF-8 LF。混合换行文件保存时若含 CRLF 则统一为 CRLF。

替换使用同目录临时文件，写入并同步后原子替换目标；新建使用禁止覆盖的持久化操作。该流程保护普通编辑器冲突与部分写入，不提供跨进程文件系统 compare-and-swap，也不承诺断电后的完整目录持久化。只读属性会在替换前检查。

外部修改在手动刷新或恢复窗口焦点时检查。编辑器干净时读取新版本；有未保存内容时保留编辑器并提示冲突。P0 无后台文件监听和自动保存。

## SQLite 的定位：已实现

| 数据 | 权威存储 | 是否可重建 |
|---|---|---|
| 剧本、提示词、说明 | Markdown | 不可丢弃 |
| 素材与视频 | 本地文件 | 不可丢弃 |
| 项目设置 | 项目 JSON | 项目标识应保留 |
| 生成任务与版本索引 | 项目 SQLite | 不可当缓存丢弃 |
| 检索索引 | 扫描结果，后续可用 SQLite | 可从文件重建 |

`generations.sqlite3` 按需建立，保存远端任务 ID、提示词、参数、输入引用、状态、结果 URL 和本地文件索引。当前选中的视频仍由 Markdown 的“视频文件名”决定；切换历史版本会走正文哈希冲突检查。数据库不保存正文和凭据。当前仅保存素材引用，不复制不可变素材快照；完整可复现归档仍待实现。全局素材库数据库与项目任务库分离，待素材库阶段实现。

复制整个项目只能携带项目内文件；绝对路径引用的外部素材不会自动归集。完整备份、导出时归集素材和在线任务恢复属于后续阶段。
