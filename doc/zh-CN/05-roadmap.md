# 05 开发阶段与 P0 清单

[English](../en/05-roadmap.md) · [目录](../README.md)

## P0：已实现的交付范围

| 子系统 | 交付 |
|---|---|
| 工程 | Tauri 2 + React/TypeScript/Vite + Rust，npm/Cargo 锁文件，Windows 图标与构建配置 |
| 项目 | 自选父目录创建，原目录打开，上级候选，最近项目，便携 JSON 身份 |
| 文本 | 大纲/总表/分集模板，原文编辑与预览，分镜导航，显式保存与另存为 |
| 兼容 | 原文件布局，中文与空格路径，UTF-8 BOM、CRLF，未知 Markdown 内容 |
| 可靠性 | 哈希冲突检测，原子替换，只读错误，未保存退出保护，外部改动刷新 |
| 素材 | 本地引用发现、存在性检查、基础预览与系统打开 |
| 文档 | AGENTS.md、双语 README、01—07 双语开发文档 |

代码存在不等于所有环境验收完成，复现命令与局限见 [07](07-development-acceptance.md)。

## 后续顺序：已规划

1. **模型配置与接口验证**：文本模型的 OpenAI 兼容协议配置；独立 H3 地址、工作流、Token 配置；验证图片/声音传输、请求与结果格式、音色效果。密钥进入系统凭据存储，不放项目文件。
2. **素材库与文本制作**：手动导入角色、场景、道具和声音；角色默认声音、项目覆盖、片段覆盖；临时角色收藏。分阶段生成大纲、剧本和分镜，用户确认后应用，保留模板与版本。
3. **视频闭环与 SQLite**：引入项目任务库及迁移、提交快照、轮询、下载、重启续查、版本选用、失败恢复。提交结果未知时不自动重发，默认串行提交。
4. **导出与备份**：FFmpeg 按选用片段顺序简单拼接并保留原声；检查缺片、规格差异及输出错误；归集外部素材、项目完整备份和恢复。

## 每阶段验收门槛

接口验证须有实际样例证据，不能用模拟成功宣称能力已验证。文本阶段须保证手动修改不被覆盖。视频阶段须验证重启、提交超时、下载失败与旧版本保留。导出阶段须核对顺序、音轨和可恢复备份。

P0 不提前建立空数据库或伪生成按钮；已完成视频对应文本的后续修改应标记影响而不是自动重新计费生成。开源发布前单独确定许可证与分发依赖许可。
