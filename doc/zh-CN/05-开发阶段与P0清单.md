# 05 开发阶段与 P0 清单

[English](../en/05-roadmap.md) · [目录](../README.md)

## P0：已实现的交付范围

| 子系统 | 交付 |
|---|---|
| 工程 | Tauri 2 + React/TypeScript/Vite + Rust，npm/Cargo 锁文件，Windows 图标与构建配置 |
| 项目 | 自选父目录创建，原目录打开，上级候选，最近项目，便携 JSON 身份 |
| 故事板 | 大纲/总表/分集模板，默认纵向卡片，字段编辑、新增/删除/移动，源码切换、分镜导航，显式保存与另存为 |
| 兼容 | 原文件布局，中文与空格路径，UTF-8 BOM、CRLF，未知 Markdown 内容 |
| 可靠性 | 哈希冲突检测，原子替换，只读错误，未保存退出保护，外部改动刷新 |
| 素材 | 本地引用发现、存在性检查、基础预览与系统打开 |
| H3 视频 | 服务地址与系统凭据配置，参考素材 Base64 请求，提交/查询、结果流式下载、Markdown 当前版本回写 |
| 生成历史 | 项目内 SQLite 任务记录，重开分镜续查，失败状态与本地历史版本选用 |
| 文档 | AGENTS.md、双语 README、01—08 双语开发文档 |

代码存在不等于所有环境验收完成，复现命令与局限见 [07](07-开发指南与验收.md)。

## 后续顺序：已规划

1. **接口实测与恢复加固**：使用有效 H3 账号验证图片/声音 Base64 传输、请求与结果格式、音色效果；补充提交结果未知的人工核对、查询退避、下载重试和多任务串行回写。
2. **素材库与文本制作**：手动导入角色、场景、道具和声音；角色默认声音、项目覆盖、片段覆盖；临时角色收藏。分阶段生成大纲、剧本和分镜，用户确认后应用，保留模板与版本。
3. **导出与备份**：FFmpeg 按选用片段顺序简单拼接并保留原声；检查缺片、规格差异及输出错误；归集外部素材、项目完整备份和恢复。

## 每阶段验收门槛

接口验证须有实际样例证据，不能用模拟成功宣称能力已验证。文本阶段须保证手动修改不被覆盖。视频阶段须验证重启、提交超时、下载失败与旧版本保留。导出阶段须核对顺序、音轨和可恢复备份。

SQLite 在首次提交任务时按需建立，不为未使用生成功能的项目创建。已完成视频对应文本的后续修改应标记影响而不是自动重新计费生成。开源发布前单独确定许可证与分发依赖许可。
