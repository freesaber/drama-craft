# 04 Markdown 格式与兼容约定

[English](../en/04-markdown-compatibility.md) · [目录](../README.md)

## 已实现：保留原文

任何 UTF-8 `.md` 文档都可以编辑。不要求 frontmatter，不把正文转换成另一套数据库模型。大纲与分镜总表优先显示，随后按数字自然排序显示分集，其他文档最后显示。子目录文档保留相对路径，鼠标悬停显示完整相对路径。

分镜导航从 Markdown 语法树的二级标题提取，格式为 `## S001 镜头名`。镜号支持大小写和不同位数；重复镜号显示诊断，并保留两个导航位置。代码块里的同形文字不当作分镜。未知段落、表格和代码块无需解析即可保存。

```markdown
# 第01集 渡口

本集内容：船工等待归来的旅人。

## S001 点灯

### 首帧生成

出图文件名：`01 首帧_S001.png`。

### 视频生成

视频文件名：`01 S001.mp4`。

| API参数 | 提示词标签 | 上传素材 |
|---|---|---|
| `ref_image_0` | `<Picture 1>` | `01 首帧_S001.png` |

**视频提示词｜duration=5，resolution=768p横**
```

该样例只说明文本组织，不表示已生成素材或已验证服务商参数。新建分集模板包含角色与音色表、素材表、首帧和视频提示词代码块。

## 本地素材

识别 Markdown 图片、链接、引用式链接及行内代码文件名；表格中的这些节点也能识别。普通文本中的裸文件名不做猜测，代码块内部不搜索素材。图片：PNG/JPG/JPEG/WebP/GIF/BMP；音频：MP3/WAV/FLAC/OGG/M4A；视频：MP4/WebM/MOV，实际播放取决于 WebView2 编解码支持。

相对路径从当前文档所在目录解析；含空格的链接可写成 `[参考图](<assets/角色 一.png>)`。Windows 绝对路径原样引用，例如 `Z:/示例素材/角色.png`。缺失文件只显示缺失，不创建假文件，也不修改引用。浏览器内预览失败可用系统应用打开。

远程链接、UNC 网络共享和可执行文件不作为 P0 素材加载。正文预览中的链接和图片保持静态，实际媒体由“素材引用”面板加载。

## 分镜总表与后续结构化编辑

总表是独立 Markdown 文档，P0 不根据分集自动重写总表。外部编辑器或创作者负责保持重复描述一致。后续表单编辑如需回写，只修改明确定位的源文本区域，保留未知内容；不让表单和 Markdown 成为两个正文权威来源。

## 与旧目录兼容

测试覆盖多集文档、每镜首帧与视频两个部分、中文空格文件名、同目录生成视频以及外部素材库路径。父目录的 AGENTS.md 不妨碍候选作品识别，也不会成为客户端的运行指令。
