# 01 产品定位与范围

[English](../en/01-product-scope.md) · [目录](../README.md)

## 目标用户与成果

为使用 Markdown 和本地素材制作短剧的个人创作者提供 Windows 工作台。作品文件夹是工作目录；离开客户端后，剧本和提示词仍可阅读、编辑和版本管理。

## 已实现：P0

项目创建与直接打开、最近项目、上级目录候选作品、文档新建/编辑/保存/另存为、Markdown 预览、分镜标题导航、本地媒体预览、外部改动检测与保存冲突保护。现有文档不会因打开或扫描而被改写。

新项目保留“大纲 → 分集文档 → 分镜”的制作组织方式，素材与视频可与文档同目录保存；子目录和外部素材路径也可引用。现有正文没有固定表单要求。

## 已规划

完整制作流程为：导入故事 → 大纲 → 分集剧本 → 分镜及生成片段 → 素材绑定 → 视频生成与选用 → 简单拼接。已有完整剧本时可以跳过大纲。素材库支持角色、场景、道具与声音，图片先手动导入。客户端不要求安装 Codex 或其他创作代理。

一个项目包含多集；一个分镜描述一个镜头；一个生成片段对应一次视频请求，可以容纳一个或多个分镜。重生成的最小单位是生成片段，历史参数和视频保留。

## 边界

Windows 优先；不自建服务端或 OSS。P0 不调用任何付费模型接口。后续只做保留原声的简单拼接，不做多轨时间线、复杂转场或字幕编辑。首帧图片可由外部工具制作，P0 只保存提示词和读取素材。

## 成功标准

新项目可在自选位置建立；旧项目保持原样接入；中文路径可用；外部编辑与客户端保存发生竞争时不静默覆盖；未知 Markdown 内容可往返保存。具体测试见 [07](07-development-acceptance.md)。
