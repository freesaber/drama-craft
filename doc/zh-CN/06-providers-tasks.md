# 06 模型接入与生成任务设计

[English](../en/06-providers-tasks.md) · [目录](../README.md)

**本文全部是后续设计，不代表 P0 已支持生成。**

## 已规划：服务商边界

文本模型先支持 OpenAI 兼容接口，配置名称、Base URL、模型名与 API Key。H3 独立配置地址、工作流、Token、并发；相同协议可换地址，不同协议必须增加适配器。Rust 随客户端执行网络业务，无须独立部署后端。

AutoDL 的通用文档与工作流页是验证入口：[API 文档](https://autodl.art/docs/comfyui_api/)、[H3 工作流](https://autodl.art/large-model/comfyui/minimax_h3_zm_u24)。下表来自前期需求提供的接口说明，实施接入时必须重新核实。

| 项目 | 需求基线，待验证 |
|---|---|
| 提交 | `/api/v1/comfyui/comfyui_workflow/minimax_h3_zm_u24` |
| 查询 | `/api/v1/comfyui/comfyui_workflow/result/{task_id}` |
| 鉴权 | `Authorization: Token…`，不默认使用 Bearer |
| 提示词 | prompt，1—10000 字符 |
| 时长 | duration，整数 1—15 秒 |
| 分辨率 | 480p/768p 横、竖、1:1，按接口实际枚举 |
| 图片 | ref_image_0 至 ref_image_8；至少一张，最多九张 |
| 音频 | ref_audio_0 至 ref_audio_2；最多三段 |
| 随机种子 | seed，可选整数 |

`ref_image_0` 对应 `<Picture 1>`，`ref_audio_0` 对应 `<Audio 1>`；映射在每次请求重新建立，图片与音频独立编号。首帧 GPT 附件编号不直接继承为 H3 参数。实际模型是否遵从标签与说话人安排需要样片验证。

## 待验证：素材与音色

优先验证 Base64 直传是否真正支持，以及是裸 Base64、data URL 还是网页先上传转换。如果只收公网 URL，确认服务商是否提供官方上传渠道；不因接入困难改为偷偷部署 OSS。若没有可用通道，则把本地素材生成标记为阻塞能力。

区分音色样本与已录对白。验证参考声音能否用于新台词、多角色怎样对应音频、单角色近景画外音是否被误配。文本创作经验可以作为模板建议，不能变成保证模型效果的产品承诺。

## 已规划：任务恢复

每次提交前持久化本地任务标识和输入快照，包括提示词、模板版本、服务商参数及素材副本或稳定内容标识。收到响应后立即保存远端 task_id。

任务流程：待提交 → 提交中 → 已受理/运行中 → 生成完成 → 下载中 → 已保存；提交超时另记“结果未知”，不得自动重发计费请求。无 task_id 的未知提交需要人工核实，不能假定可恢复。查询与下载可以退避重试，下载失败不重新生成。

结果 URL 可能过期，成功后及时下载到临时文件，完成后落为本地版本；重启继续查询已知任务。旧视频、旧提示词与素材快照保留，用户手动选用版本。暂停仅停止后续提交，不等同取消云端任务。托盘后台运行、关闭提示与休眠后的过期结果处理在视频阶段实现。

API Key 与 Token 存于操作系统凭据存储；日志脱敏，备份不带密钥。P0 不存密钥，也不发送模型请求。
