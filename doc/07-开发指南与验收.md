# 07 开发指南与验收

## 环境与运行

Windows 10/11、Node.js 22、npm、Rust stable 的 MSVC 工具链、Visual Studio C++ 桌面开发组件和 WebView2。参考 [Tauri 环境要求](https://v2.tauri.app/start/prerequisites/)。开发默认端口 1420，若被占用明确退出，不自动换端口。首次 `tauri dev` / `tauri build` 会按 `src-tauri/ffmpeg.lock.json` 下载 FFmpeg 8.1.2 Windows essentials sidecar；也可单独运行 `npm run ffmpeg:download`。Rust 测试需要该 sidecar。

```powershell
npm ci
npm run ffmpeg:download
npm run tauri dev
```

`npm run dev` 只展示浏览器界面，不提供本地文件功能。`npm run tauri build -- --no-bundle` 输出 `src-tauri/target/release/drama-craft.exe`；不带 `--no-bundle` 时打包 NSIS。图标由原创几何图形脚本生成，不依赖私人素材。

## 自动检查

```powershell
npm run check
npm test
npm run build
npm run docs:check
cargo test --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

Markdown 测试覆盖真正标题与代码块的区别、重复镜号、表格/行内代码/引用式链接素材、中文绝对路径、远程素材排除及自然排序。Rust 临时目录测试覆盖 BOM/CRLF 保存、外部冲突、删除后保存、路径越界、Windows 名称、只读属性、移动后项目标识、损坏元数据、素材缺失和非 UTF-8。

生成链路测试使用本机临时 HTTP 服务，不发送计费请求：验证提交/查询路径、Authorization 请求头、本地图片/音频 data URL、默认 seed 数值传输、音视频 MIME 编码、任务配置绑定、完成结果流式下载和 SQLite 历史记录。它只验证客户端协议实现，不能证明真实服务接受 Base64 或音色有效。

故事板回归额外覆盖独立行/无标题编号、非分镜区间、重复/缺失/无法识别字段、全文引用定义、局部字段回写、过期草稿拒绝、CRLF、围栏扩展和连续剧情输入。

## 真实目录只读检查

设置 `DRAMACRAFT_COMPAT_DIR` 为本机作品目录，然后运行忽略的兼容测试：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml external_workspace_readonly_check -- --ignored
```

该检查直接使用只读扫描/读取，不调用项目初始化，并对比所有文件的前后哈希。预期样本为 12 集；分镜识别的目标为 184 镜，首集 13 镜。真实路径不写入仓库，素材与文稿不复制为公开测试样例。

## 当前版本边界

当前没有文本模型、后台常驻轮询、任务取消、素材库、完整备份或多轨时间线。历史生成视频可裁切片头片尾并覆盖原文件；本集勾选的当前视频可合并为 `01 merge_时间戳.mp4`。只有已知远端 `task_id` 能在重开分镜后续查；提交响应丢失时不会自动重发，也暂时无法自动核对。预览受系统编解码能力限制，混合换行保存会规范化，原子替换不等于跨进程 compare-and-swap。人工正在编辑的内容不会在自动刷新时被覆盖。

当前仓库没有开源许可证，构建产物也没有安装包签名记录。不要把编译成功写成尚未执行的 UI 或云端验收通过。
